# 知行题库

共 **1412 题**：原有教育学、心理学、教育政策与法规 898 题，加上 18 套浙江生物真题 514 题（424 道选择题、90 道非选择题）。支持按科目、试卷、题型筛选，顺序或随机练习、错题、收藏和GitHub进度同步。

在线使用：[知行题库](https://211820252.github.io/zhixing-question-bank/)（iOS、Windows 和 macOS 浏览器均可打开）。选择题自动判分；大题先独立作答，点击“查看参考答案”，再选“我做对了”或“我做错了”，自评后计入练习和错题。

原 898 题及 ID 保持不变，继续使用原来的本地存储键，更新网页不会主动清空旧进度。进度默认保存在当前浏览器，连接GitHub后同步到仓库；清理网站数据会删除本机记录。

刷题时会偶尔出现给“洁猪”的鼓励和表情：每完成8次作答、每答对6次或每连续答对4次，有35%／45%／55%的概率触发；同次只选择一种，连对优先。两次至少间隔8次作答和90秒，卡片5.2秒后自动收起，也可手动关闭。只统计实际提交的答案（包括大题自评），查看答案、刷新和同步旧进度不会触发；答错会重置连对数。鼓励计数与间隔保存在本机，不改动答题记录或GitHub同步格式。

## 跨设备同步

页面点击“同步到我的仓库”，首次按弹窗链接创建专用令牌并粘贴一次即可；仓库已经预设，不需要填写其他参数。默认记住这台设备，以后点一下就同步，答题后也会自动保存。换设备首次连接后自动合并答题、错题、收藏和本轮位置。网络断开仍会保存在本机。

使用原仓库 `211820252/zhixing-question-bank` 的 `progress` 分支和 `progress/personal.json`，不会因保存进度重新部署网站。**仓库是公开的，因此同步的练习记录也公开。** 令牌由设备单独保存，不进入源码或进度文件；默认记住本机浏览器，取消“记住这台设备”则仅保留在本次标签页会话。GitHub要求写入授权，不能将令牌作为公共网页默认值。配置细节及冲突处理见 [同步说明](docs/github-sync.md)。

## Windows 直接使用

将 [知行题库-Windows直接打开.html](知行题库-Windows直接打开.html) 放到 Windows 或 macOS 电脑，双击即可在浏览器中打开，不需要安装软件或联网。题目、解析与全部图片已内嵌在这一个文件里。练习进度保存在当前浏览器；跨设备同步需要联网并首次连接GitHub。

## iPhone 使用

页面已适配手机屏幕，iPhone 用 Safari 打开上方网址即可使用。直接从 iPhone“文件”应用打开本地 HTML 时，各浏览器对脚本和本地存储的支持不同，因此建议通过网址打开。

## 重新生成

```sh
node scripts/build-question-bank.mjs /path/to/题目.txt
node scripts/build-standalone.mjs
```

浙江试卷整理脚本、题号覆盖与来源见 [导入说明](imports/zhejiang/README.md)。运行网站直接使用已生成的 `data.js`、`zhejiang-data.js` 和 `assets/`，不需要安装依赖。发布脚本通过现有 GitHub CLI 凭据上传增量文件，不会把凭据写入网站。

题目与解析主要保留原资料措辞；有出处的勘误会在作答后标注来源。教育政策与法规部分含较早年份的材料，涉及现行规定时应另行核对。
